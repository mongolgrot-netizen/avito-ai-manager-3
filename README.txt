AVITO AI MANAGER — MOBILE PWA MVP

Это статическая мобильная PWA-версия. Она работает в браузере Android и может быть установлена на главный экран.

ВАЖНО: реальное подключение Avito и серверный AI пока не включены. Следующий этап — разместить backend в интернете и подключить официальный API Avito и AI.

Файлы проекта: index.html, style.css, app.js, sw.js, manifest.webmanifest, icon.svg.
